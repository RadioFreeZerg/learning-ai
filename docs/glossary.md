# Glosario / Glossary

Términos del curso en español y su equivalente en inglés. / Course terms in Spanish with their English equivalents.

| Español | English | Significado breve |
| --- | --- | --- |
| Asistente de IA | AI assistant | Programa con el que conversas para pedirle textos, ideas o análisis. |
| Modelo de lenguaje | Language model | Sistema que genera texto prediciendo qué palabras encajan mejor a continuación. |
| Instrucción (prompt) | Prompt | Texto que escribes para pedir algo al asistente. |
| Contexto | Context | Información que das al asistente para que ajuste su respuesta. |
| Ventana de contexto | Context window | Cantidad de texto que el asistente puede tener en cuenta a la vez. |
| Iteración | Iteration | Mejorar un resultado en rondas sucesivas con correcciones concretas. |
| Invención (alucinación) | Hallucination | Dato o fuente que suena plausible pero no existe o es falso. |
| Verificación | Verification | Comprobar una afirmación con un método o fuente independiente del asistente. |
| Sesgo | Bias | Tendencia sistemática a favorecer o perjudicar a ciertas personas o ideas. |
| Anonimizar | Anonymize | Quitar o sustituir datos que permiten identificar a una persona. |
| Semáforo (de riesgo o de datos) | Traffic light | Clasificación en verde, amarillo y rojo según riesgo o sensibilidad. |
| Agente | Agent | Sistema que recibe un objetivo, decide pasos y actúa con herramientas. |
| Flujo de trabajo | Workflow | Secuencia de pasos, humanos y asistidos, para lograr un resultado. |
| Punto de control humano | Human checkpoint | Paso donde una persona revisa o aprueba antes de continuar. |
| Rúbrica | Rubric | Criterios con niveles para valorar un entregable. |
| Aviso | Warning | Marca de que avanzaste sin aprobar un ejercicio y puedes retomarlo. |
| Tarjeta de continuidad | Continuity card | Resumen breve que pegas para retomar el curso en un chat nuevo. |
| Progreso | Progress | Registro de lecciones, ejercicios y avisos (`progress.json` o tarjeta). |
